# Između dva svijeta

Narativna igra izbora izrađena u Unityju i Yarn Spinneru.

Igrač preuzima ulogu Kaela, lingvista koji uspostavlja kontakt s podzemnom civilizacijom Dhorn. Prevođenjem poruka i donošenjem odluka utječe na povjerenje dviju strana i otključava jedan od četiri završetka.

## Tehnologije

- Unity 6
- C#
- Yarn Spinner
- TextMesh Pro
- Unity Input System

## Pokretanje projekta

1. Klonirati repozitorij.
2. Otvoriti projekt u Unityju 6000.3.18f1.
3. Otvoriti scenu `MainMenu`.
4. Pokrenuti igru.

## Kontrole

- Enter / Space / lijevi klik — nastavak dijaloga
- Miš — odabir opcija
- ESC — pauza
